# 自动化与 Heartbeat 示例

## 独立定时任务

适合每次从同一个稳定提示开始、结果互不依赖的工作。

```text
每周检查这个项目的 codex-lab/progress.md 和 records/。只有当出现新增完成记录、连续七天无进展、验证失败或需要我决定的事项时才通知我；没有有意义变化时保持安静。输出本周完成项、证据缺口、一个最小下一步和需要我处理的问题。不要修改源 PDF，不要代替我勾选未验收课程。
```

## 同线程 Heartbeat

适合保留当前学习上下文并在同一任务继续跟进。

```text
每周回到本任务检查学习进度。沿用已有评分和错误记录，只在进度、失败或所需行动发生变化时更新我；不要重复上次没有变化的总结。
```

## 创建前检查

- 明确时区、首次运行时间和重复频率。
- 明确是在当前线程继续，还是每次创建独立运行。
- 本地文件任务需要电脑开机、桌面应用运行且项目路径仍可用。
- 提示必须包含输入、权限、通知条件和停止条件。
- 先手动运行一次提示，验证后再计划。
