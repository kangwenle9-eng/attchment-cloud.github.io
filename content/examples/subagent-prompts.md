# 子智能体练习提示

## 什么时候适合拆分

只有同时满足以下条件时才并行：子任务有清晰边界；可以独立读取；不会同时修改同一文件；主 Agent 能用统一标准验收。

## 第 18 天双角色练习

给主 Agent：

```text
分析 week-06-python-automation.pdf。若当前环境支持子智能体，请并行委派两个只读子任务：
1. 结构研究员：提取第 3-9 页的每日目标、产出和过关标准，不提出改写。
2. 测验审查员：根据同一资料设计 5 道题，并逐题说明证据页码。
主 Agent 收到结果后检查题目是否真的由结构研究结果支持，指出冲突并给出最终版本。所有输出写入新的练习目录，不修改源 PDF。
```

## 主 Agent 汇总清单

- 两个子任务是否使用同一输入版本？
- 是否有人越过只读边界？
- 结论冲突在哪里，依据是什么？
- 最终采用、修改和拒绝了哪些内容？
- 是否由主 Agent 做了独立抽查？

若当前环境没有子智能体能力，在两个独立只读任务中执行相同角色，再由第三轮主任务汇总；记录这是模拟，不声称真实并行。
