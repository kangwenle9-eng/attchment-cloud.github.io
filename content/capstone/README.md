# 综合项目：Codex 学习资料助理

## 统一输入接口

每次运行前复制并填写：

```text
输入资料路径：<单个 PDF 或资料目录>
学习目标：<希望理解或掌握什么>
输出目录：codex-lab/capstone/runs/<运行名称>
验收标准：<使用本页默认标准，或写明调整>
```

## 必需交付物

每次运行在独立输出目录生成：

1. `brief.md`：填写完成的任务书、范围和限制。
2. `inventory.json`：输入文件、页数、大小、哈希与文本覆盖情况。
3. `summary.md`：结构化摘要，事实与推断分开。
4. `knowledge-points.md`：关键概念、解释、来源位置和易错点。
5. `quiz.md`：不少于 8 道题，覆盖回忆、解释和迁移。
6. `answer-key.md`：答案、评分点与证据位置。
7. `evidence.md`：关键结论到文件/页码的映射。
8. `quality-report.md`：完整性、证据、题目质量、安全和已知限制。

## 推荐执行流

1. 读取任务书，确认源资料保持只读。
2. 显式调用 `$learning-material-analyzer`。
3. 运行 Skill 的资料清单脚本，确认输入和哈希。
4. 完整读取相关页面，并对有布局意义的页面进行视觉抽查。
5. 生成摘要、知识点、练习和答案。
6. 若子智能体可用，将“结构提取”和“测验审查”作为两个独立只读子任务；主 Agent 负责汇总和裁决。
7. 按输出契约和评分表检查，修复后再交付。
8. 重新核对源资料哈希，证明没有覆盖原文件。

## 100 分验收

- 输入清单和源文件保护：15 分。
- 摘要忠实、结构完整：20 分。
- 知识点解释准确且可追溯：20 分。
- 练习题有层次且答案可评分：20 分。
- 关键声明的文件/页码证据：15 分。
- 未知项、限制和安全说明：10 分。

70 分通过；源资料被覆盖、伪造引用或隐瞒读取失败时直接不通过。
