# B 站辅助学习导航

> 核验日期：2026-09-19。以下资源根据公开视频标题、简介、章节和 UP 主信息筛选。B 站内容可能改名、下架或更新；视频用于建立直觉，Codex 当前功能和配置始终以 OpenAI 官方文档与当前应用实测为准。

## 推荐 UP 主

### 1. Easonlee：Codex 全局入门

- 代表视频：[OpenAI官方：Codex新手教程](https://www.bilibili.com/video/BV19MzXBNESV/)
- 适合：第 1-10 天。
- 重点看：Codex CLI、VS Code、工作流、`AGENTS.md` 和提示模式。
- 学法：先看整体演示，再回到本实验室用自己的目录重复；不要照抄安装步骤或配置值。

### 2. GoldenSpiderAI：Codex 入口与高级工作流

- 代表视频：[Codex 入门指南](https://www.bilibili.com/video/BV11erUBUEEX/)
- 适合：第 1、8、10、19 天。
- 重点看：CLI/IDE、`AGENTS.md`、无头模式与 SDK 的概念边界。
- 学法：零基础阶段只学习任务组织和规则文件；SDK 内容先知道用途，不要求立即编程。

### 3. AI王知风：Windows 与 AGENTS.md

- 代表视频：[Codex新手入门第二期：看懂 AGENTS.md 规则文件](https://www.bilibili.com/video/BV1WtKQ6qEzV/)
- 适合：第 8-10 天。
- 重点看：全局规则、项目规则、子目录规则以及作用域差异。
- 学法：观看后对照本项目根目录 `AGENTS.md`，找出哪些规则是项目专属，哪些更适合个人全局配置。

### 4. 阿喵讲AI：真实任务与配置思路

- 代表视频：[Codex深度配置指南：入口、AGENTS.md 与真实任务](https://www.bilibili.com/video/BV1hAVm6XEHT/)
- 适合：第 4、8、10、19 天。
- 重点看：App、命令行和编辑器入口的选择，如何让规则保持简洁，以及为什么隔离任务状态。
- 学法：把视频里的配置当作案例，而不是直接复制；先在 `.example` 文件中解释每一项。

### 5. 技术爬爬虾：Skills 与 MCP

- 代表视频：[Agent Skills 详细攻略](https://www.bilibili.com/video/BV1HuiyBQE9G/)
- 进阶视频：[MCP 如何对接大模型：底层原理](https://www.bilibili.com/video/BV1P3XTYPEJm/)
- 适合：第 11-18 天。
- 重点看：Skill 的结构、触发与复用，Skill 和 MCP 的分工，工具参数怎样进入模型上下文。
- 学法：不同产品的 Skill 细节可能不同；把通用思想迁移到本项目 Skill，Codex 具体目录和字段回到 OpenAI 官方文档核验。

### 6. 隔壁的程序员老王：Agent 心智模型

- 代表视频：[10分钟讲清楚 Prompt、Agent、MCP 是什么](https://www.bilibili.com/video/BV1aeLqzUE6L/)
- 适合：第 13、15-17 天。
- 重点看：Prompt、Agent、工具和 MCP 的层次关系。
- 学法：观看后必须自己画出“观察 → 规划 → 行动 → 验证 → 修正”循环，并用本项目实例解释，不能只记名词。

### 7. 黑马程序员：Git 基础补课

- 代表视频：[Git 全套教程：项目管理工具](https://www.bilibili.com/video/BV1MU4y1Y7h5/)
- 适合：第 19 天及以后。
- 重点看：工作区、暂存区、仓库、提交、分支和冲突。
- 学法：只需先看基础命令与分支章节。该视频发布时间较早，Git 基础概念仍适用，但 Codex worktree 的具体操作以当前课程和官方文档为准。

## 30 天观看搭配

| 课程阶段 | 建议视频 | 建议观看量 | 看完必须完成的动作 |
|---|---|---:|---|
| 第 1-7 天 | Easonlee 或 GoldenSpiderAI | 30-60 分钟，分两次 | 用当前目录完成一次只读检查和任务书 |
| 第 8-10 天 | AI王知风、阿喵讲AI | 每天 10-20 分钟 | 逐条解释本项目 `AGENTS.md` 与配置示例 |
| 第 11-14 天 | 技术爬爬虾 Skills | 30-60 分钟 | 运行并验收项目级学习资料 Skill |
| 第 15-18 天 | 隔壁的程序员老王、技术爬爬虾 MCP | 20-40 分钟 | 画 Agent 循环并完成一次并行拆分 |
| 第 19 天 | 黑马程序员 Git 基础与分支章节 | 30-60 分钟 | 在 `tmp/` 隔离目录完成分支/worktree 练习 |
| 第 20-30 天 | 回看对应章节，不新增长课 | 每周不超过 90 分钟 | 把时间留给 Hooks、自动化、调试和综合项目 |

## 视频筛选规则

- 优先选择展示真实操作、错误处理和验证步骤的视频。
- 标题中的“精通”“零基础到大神”不作为质量证据；以内容结构和实际练习判断。
- 遇到模型名称、价格、默认设置、安装命令和权限行为，检查发布日期并查询当前官方文档。
- 不运行来源不明的整合包、破解工具、登录绕过、账号共享或评论区脚本。
- 不为了领取课件提交密码、Cookie、API 密钥或客户资料。
- 每看完一个视频，至少完成一个可验证动作；只收藏不算学习进度。
